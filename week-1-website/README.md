# Week 1 — Personal Profile Website

## Overview
A responsive personal profile website built as part of my Week 1 internship task. It uses HTML, CSS, and JavaScript.

## Features
- Semantic HTML structure
- Responsive layout for desktop and mobile screens
- CSS styling using layout techniques
- JavaScript interactions
- Profile and project sections

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open the `week-1-website` folder.
3. Open `index.html` in a web browser.

No build step is required.

## Testing
The project includes `checks.js` and `browser-check.js` for local checks.

## Project Structure
- `index.html` — website structure
- `style.css` — layout and styling
- `script.js` — interactive behavior
- `checks.js` — local checks
- `browser-check.js` — browser checks
