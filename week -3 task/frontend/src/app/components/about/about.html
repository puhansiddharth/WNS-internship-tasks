The frontend is constructed using Angular's modern Standalone Component architecture. Legacy NgModule declarations have been replaced with self-contained imports.

  • Root Component (App): Houses the layout structure, sticky navigation, and <router-outlet>.
  • Environment Config: environment.ts centralizes the API base URL (http://127.0.0.1:5000).
  • Change Detection: Configured with provideZonelessChangeDetection() and explicit ChangeDetectorRef.markForCheck().

The backend application is implemented in backend/app.py as a clean, stateless REST API server:

  • Defensive JSON Parsing: Verifies request.is_json and inspects payloads via request.get_json(silent=True) to prevent unhandled 500 crashes.
  • Input Sanitization: Trims whitespace from incoming strings and rejects empty values with HTTP 400 Bad Request.
  • Standardized JSON Handlers: Custom error handlers for 400, 404, 405, and 500 guarantee that errors are returned as JSON, never raw HTML.
}

In accordance with the Single Responsibility Principle, components never make direct HTTP calls. All networking is centralized in ApiService:

  • Decorated with @Injectable({ providedIn: 'root' }), making it an application-wide singleton.
  • Injected into components via constructor injection: constructor(private apiService: ApiService).
  • Decouples presentation logic from network transport and error normalization.
}

Angular HttpClient operates using RxJS Observables rather than standard Promises. Observables provide powerful advantages:

  • Type Generics: http.post<GreetResponse>(url, body) ensures strict compile-time payload safety.
  • Pipeline Operators: Operators like catchError() and finalize() provide seamless lifecycle control.
  • Cancellation: Subscriptions can be unsubscribed or canceled before response arrival if needed.
}

Browsers enforce the Same-Origin Policy (SOP). Because the Angular app runs on http://localhost:4200 and Flask runs on http://127.0.0.1:5000, the browser treats requests as cross-origin.

  • Preflight OPTIONS Request: When sending JSON headers, the browser automatically sends an HTTP OPTIONS probe.
  • Flask-CORS Middleware: Intercepts preflight requests and replies with Access-Control-Allow-Origin: http://localhost:4200.
  • Without these response headers, the browser blocks the incoming response for security reasons.
}

Angular Reactive Forms provide a synchronous, programmatically testable form model. In GreetingComponent:

  • FormGroup & FormBuilder: Form structure is defined in TypeScript rather than the template.
  • Validation Pipeline: Combines Validators.required, Validators.minLength(2), and a custom nonWhitespaceValidator.
  • Defensive Execution: If the user enters whitespace or leaves the field blank, markAllAsTouched() highlights errors instantly without triggering unnecessary network calls.
}

  1. User Interaction: User enters name and clicks "Say Hello".
  2. Client Validation: Angular Reactive Forms verifies that the name meets all validation criteria.
  3. Loading State: isLoading = true disables the button and activates the spinner.
  4. Service Dispatch: ApiService.greet(name) posts JSON payload to http://127.0.0.1:5000/greet.
  5. Flask Processing: Backend verifies JSON, sanitizes string, and responds with HTTP 200 OK.
  6. Observable Emission: next() receives response; finalize() resets isLoading = false.
  7. DOM Update: Angular Zoneless scheduler renders the personalized greeting banner immediately.
}

The application uses a multi-tiered error handling pattern:

  • Status 0 (Network Offline): If Flask is not running, handleError() catches status 0 and displays a friendly message prompting the user to start the server.
  • Status 400 (Validation Failure): Server error messages are extracted directly from the response JSON and displayed cleanly.
  • UI Recovery: Buttons are re-enabled, loading spinners are dismissed, and the user can retry without reloading the page.
}
