Under the Hood: How JavaScript Communicates with Flask

  1. User Action: Button click or form submit triggers a JavaScript event listener.
  2. Fetch Request: fetch(url, options) initiates an asynchronous HTTP request.
  3. CORS Check: Browser sends origin headers; Flask backend verifies allowed origins via Flask-CORS.
  4. Payload Processing: Flask parses JSON, validates input fields, and returns a JSON response with status code.
  5. DOM Update: JavaScript awaits the promise, extracts await response.json(), and renders the UI dynamically.
