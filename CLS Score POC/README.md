# Angular CLS Demonstration POC

This repository contains the Cumulative Layout Shift (CLS) proof-of-concept project built for internship task demonstration.

## Project Location

The complete Angular project is located in the [`angular-cls-demo`](./angular-cls-demo) directory.

## Quick Start (PowerShell)

```powershell
# Navigate into the project
cd angular-cls-demo

# Start the application
npm start
```

Open `http://localhost:4200` in Google Chrome.

For full architectural details, Chrome DevTools verification steps, and the mentor presentation script, see [`angular-cls-demo/README.md`](./angular-cls-demo/README.md).
